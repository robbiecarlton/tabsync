# Changelog

All notable changes to `@tabsync/extension` are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this
package adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.0.0] - 2026-10-23

### Changed

- First stable release; no functional changes from the previous version.

## [0.6.1] - 2026-10-23

### Fixed

- Applying no longer dissolves and rebuilds every group in a window that changed (which made
  collapsed groups flicker open) or moves every tab. Existing groups are reused and only tabs
  and groups that are out of place are touched.

## [0.6.0] - 2026-10-23

### Changed

- The default server URL is the deployed server, `https://tabsync-production.up.railway.app`,
  which the manifest now grants (alongside `http://localhost:8787` for development). Existing
  installs keep their saved server URL.

## [0.5.1] - 2026-10-23

### Changed

- Snapshots no longer include inline `data:` favicons (via shared 0.3.0), removing the only
  realistic way to exceed the server's size limit.
- The size-limit error now reads "The snapshot is too large to sync (over the server's size
  limit)", since the 2 MB cap applies to the whole request, not the snapshot alone.

## [0.5.0] - 2026-10-23

### Added

- Extension icon (two offset browser windows), generated by `scripts/make-icons.mjs`.

### Changed

- An unreachable server now shows Pending straight away, then Error after 5 minutes, even
  when there's nothing to push.
- Persistent failures (rejected credentials, clock skew, snapshot too large) are retried every
  5 minutes instead of every minute, and pulls pause meanwhile; Retry / Sync now still retry
  immediately.
- Clearer error messages, e.g. for clock skew, the 2 MB snapshot limit, rate limiting, server
  errors, an unrecognised profile and snapshots that can't be decrypted.

## [0.4.0] - 2026-10-22

### Added

- Conflict state (amber "!"): this device has unpushed edits and another device pushed newer
  tabs. The popup lists tabs only here and only on the other device, with **Merge**, **Keep
  mine** and **Take theirs**.
- The server's latest is re-checked right before every push, so a device that edits before
  its next pull reports a conflict instead of overwriting the other device's tabs.
- History in the popup: one restore point per label (1 minute … 1 year) with real time,
  device and tab count, plus "Undo last apply or restore". Restore uses the same mode choice,
  saves an undo point first, and syncs the result to other devices.

## [0.3.1] - 2026-10-22

### Fixed

- Apply failed with "Invalid value for state" when it had to open a window for a snapshot
  window that was maximized: Chrome rejects `state: "maximized"` with `focused: false`.
  Windows are now created plain and maximized afterwards; fullscreen is no longer restored.
- A tab the browser refuses to open no longer aborts the whole apply; it's left out and
  logged.
- Apply errors now say that the previous tabs were saved first.

## [0.3.0] - 2026-10-22

### Added

- Pull: checks the server on popup open, window focus (throttled to 30 s), the 1-minute
  alarm and Sync now, using `If-None-Match` so unchanged polls are cheap.
- Behind state: blue "!" badge; the popup shows "<device> has newer tabs (3 opened, 1 closed,
  …)" with Apply and the Add missing only / Make it match exactly choice (remembered per
  device, default Add missing only), plus an opt-in to close surplus windows.
- Reconcile: windows matched by overlap (blank windows reused), tabs matched as a multiset,
  missing tabs created unloaded, pinned tabs first and in order, groups rebuilt with title,
  colour and collapsed state, unmatched tabs closed last in match-exactly mode. Internal
  pages are never closed.
- A `pre-restore` snapshot is saved before every apply; if it can't be saved nothing changes.
- Echo suppression: the applied snapshot becomes the base and the result isn't pushed back.
- A newer snapshot identical to the local layout is adopted without prompting.

### Changed

- Pushes are held while Behind, so a newer snapshot from another device is never overwritten.
- After joining, the profile's latest tabs show as Behind instead of Synced.

## [0.2.0] - 2026-10-22

### Added

- Options page: create a new sync profile (secret shown once with a password-manager prompt),
  join with a secret (clear errors for malformed or unknown secrets; nothing stored on
  failure), device name and server URL (with a runtime permission request for custom
  servers), reveal secret behind a confirm, disconnect, and a debug log of the last 50 lines.
- Popup: status, device name, last push time, last error, Sync now / Retry.
- Background sync engine: captures normal windows, tabs and groups; pushes encrypted snapshots
  5 s after the last change (30 s max during continuous activity); skips unchanged
  fingerprints and empty layouts; persists pending snapshots across worker and browser
  restarts; 1-minute alarm safety net; retry with backoff; ignores session-restore churn.
- Toolbar badge for Not set up / Pending / Synced / Error.
- `optional_host_permissions` so a custom server URL can be granted per origin.

## [0.1.0] - 2026-10-22

### Added

- Manifest V3 build (Vite, Preact) with the manifest generated from `src/manifest.ts`.
- Placeholder service worker, popup and options page.
